Seek flash-id over WebUSB

Reads the SPI-flash chip identity and protection status out of a Seek Thermal Compact running firmware 4.8.1.9 (289d:0010, "PIR206") — entirely from Chrome, no drivers, no J-Link. The probe is strictly read-only. The separate Unlock button (after an explicit confirmation) writes only the chip's protection registers — the flash array is never erased or programmed.

Log

How it works: the page stages a small code probe into the camera's RAM through an RPC staging window (wires 90/67), arms the deferred one-shot timer (wire 89), and the probe runs once from RAM with interrupts masked: it takes the SPIFI controller out of memory-mapped mode, issues read commands to the flash chip (0xFF, 0x9F, 0x05/0x35/0x15, 0x2B, 0x3D block-lock read), restores mapped mode, and parks 16 result bytes where the page reads them back over the RPC window getter. Requires Chrome or Edge (WebUSB) and the camera on firmware 4.8.1.9. The Unlock button additionally issues the Winbond status-register writes (0x01/0x11), Global Block Unlock (0x98) and Write Disable (0x04) — guarded: a non-Winbond chip or SRP1 set means nothing is written. Status-register semantics per Winbond W25Q / Macronix MX25L / Spansion S25FL-P datasheets.
